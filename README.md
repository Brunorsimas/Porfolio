# Portfólio Bruno Rafael

## 🚀 Sobre o Projeto

Portfólio profissional desenvolvido para apresentar minhas habilidades técnicas, experiência profissional e projetos desenvolvidos na área de Tecnologia da Informação. O site foi construído com tecnologias modernas de front-end, focando em uma experiência visual impactante e navegabilidade intuitiva.

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica e acessibilidade
- **CSS3** - Estilização moderna com animações e gradientes
- **JavaScript** - Interatividade e filtros dinâmicos
- **SVG e CSS locais** - Ícones e tipografia sem dependências externas
- **Node.js** - Validação automatizada de HTML, referências e Lighthouse

## 🎯 Destaques Técnicos

### Performance e Otimização
- **CSS Modular**: Arquivos CSS separados por funcionalidade
- **Animações Otimizadas**: Uso de transform e opacity para performance
- **Lazy Loading**: Animações ativadas por scroll
- **Mobile-First**: Design responsivo com breakpoints estratégicos

### Acessibilidade
- **Semântica HTML5**: Tags header, main, section, footer
- **ARIA Roles**: role="banner", "contentinfo", "region"
- **Navegação por Teclado**: Links e botões acessíveis
- **Contraste**: Cores com boa relação de contraste

### Interatividade
- **Filtros Dinâmicos**: Sistema de filtragem de projetos por categoria
- **Animações de Scroll**: Elementos aparecem com scroll
- **Hover Effects**: Feedback visual em elementos interativos
- **Transições Suaves**: Experiência de navegação fluida

## 🚀 Como Visualizar

1. **Clone o repositório**:
   ```bash
   git clone [URL-do-repositório]
   cd "Site Portfolio"
   ```

2. **Abra o site**:
   - Dê duplo clique em `index.html`
   - Ou use um servidor local:
     ```bash
     # Python 3
     python -m http.server 8000
     
     # Node.js
     npx serve .
     ```

3. **Navegue** pelas seções usando o menu de navegação
